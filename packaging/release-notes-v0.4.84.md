# Apocalipse Download Manager 0.4.84

## Português do Brasil

Corrige o tema escolhido voltando ao padrão após reiniciar o programa ou o Windows. Na inicialização, o ADM agora recupera o tema salvo em settings.json, sem sobrescrevê-lo com a memória da janela. O usuário validou a correção após reiniciar o Windows usando a extensão existente.

A extensão 0.3.190 permanece inalterada; não é necessário atualizá-la para esta correção. Pacotes Windows x64, Linux x64 portátil/AppImage e macOS x64.

## English

Fixes the selected theme reverting on application or Windows restart. Startup now restores the theme from settings.json instead of overwriting it with a missing or stale webview cache. The user validated the fix after restarting Windows with the existing extension.

Browser extension 0.3.190 is unchanged and does not need updating for this fix. Windows x64, Linux x64 portable/AppImage and macOS x64 packages.

## 简体中文

修复重启程序或 Windows 后所选主题恢复为默认值的问题。启动时从 settings.json 恢复主题，避免窗口缓存缺失或过期时覆盖配置。用户已在 Windows 重启后使用现有扩展验证此修复。

浏览器扩展 0.3.190 保持不变，无需为此修复更新扩展。提供 Windows x64、Linux x64 便携版/AppImage 和 macOS x64 软件包。
