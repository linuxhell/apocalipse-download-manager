Apocalipse Download Manager - ED2K engine

This directory contains the official aMule 3.0.1 runtime for this operating system.
Apocalipse uses ed2k.exe, amulecmd.exe and amuled.exe/amule.exe from this directory.
Keep the DLL files beside the executables; they are a matching set and must not be
updated individually.
