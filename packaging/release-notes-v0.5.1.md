# Apocalipse Download Manager 0.5.1 — Extensão 0.3.204

## Português do Brasil

Corrige a janela do Apocalipse Link (layout em três colunas, sem texto empilhado) e deixa na aba Link das Configurações apenas o botão para abrir a janela separada. Abrir o app pela bandeja ou por um link do navegador agora sempre usa o tamanho do IDM (980×620), centralizado.

## English

Fixes the Apocalipse Link window layout (three columns, no stacked text) and leaves only the "open in a separate window" button in the Settings Link tab. Opening the app from the tray or from a browser link now always uses the IDM size (980×620), centred.

## 简体中文

修复 Apocalipse Link 窗口布局（三栏，不再文字堆叠），设置中的 Link 标签页只保留“在单独窗口中打开”按钮。从托盘或浏览器链接打开应用时，始终使用 IDM 大小（980×620）并居中。
