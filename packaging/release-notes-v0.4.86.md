# Apocalipse Download Manager 0.4.86

## Português (Brasil)
- Interface compacta para downloads, torrents e gravações, com painéis transparentes e botões na cor do tema.
- Visualizar nas ações, disponível apenas para áudio ou vídeo com dados no disco.
- Rolagem da lista preservada, com barra oculta até interação.
- Extensões Chrome, Edge e Firefox 0.3.195: fundo dos botões Baixar/Gravar acompanha o tema desde a criação, com texto legível.
- Ajustada a visibilidade dos botões durante a rolagem e em contêineres de layout.
- Firefox inclui o XPI assinado fornecido pelo mantenedor.

## English
- Compact download, torrent and recording queues with transparent panels and theme-colored buttons.
- Preview actions available only for audio/video payloads with data on disk.
- Preserved list scrolling with scrollbars hidden until interaction.
- Chrome, Edge and Firefox extensions 0.3.195 apply readable theme colors when overlay buttons are created.
- Improved overlay visibility while scrolling and inside layout containers.
- Firefox includes the signed XPI provided by the maintainer.

- 保持列表滚动位置，交互时显示滚动条。
- Chrome、Edge 和 Firefox 扩展 0.3.195：按钮创建时立即应用主题颜色，并保持文字清晰。
