# Apocalipse Download Manager 0.5.8 — Extensão 0.3.205

## Português do Brasil

O ADM não mostra mais uma tela branca ao iniciar com o Windows (a janela só aparece quando a interface está pronta, e nunca no início oculto pela bandeja). O modo escuro agora é salvo e volta ao reabrir o ADM. ADM e extensão ganharam contorno preto de 1 px.

## English

ADM no longer flashes a blank white window when it starts with Windows (the window only appears once the UI is ready, and never on a tray-hidden start). Dark mode is now saved and restored when ADM reopens. ADM and the extension now have a 1 px black outline.

## 简体中文

ADM 随 Windows 启动时不再闪现空白窗口（窗口仅在界面就绪后显示，托盘隐藏启动时不显示）。深色模式现在会保存，重新打开 ADM 时恢复。ADM 和扩展现在都有 1 像素的黑色边框。
