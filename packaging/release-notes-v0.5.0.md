# Apocalipse Download Manager 0.5.0 — Extensão 0.3.203

## Português do Brasil

Nova janela compacta, do tamanho do IDM (980×620): fundo branco, texto preto e os temas foram removidos. Navegação: Downloads, Torrents, Gravações, Configurações, Doação e Sobre. Ferramentas, idioma, rede, extensão, Apocalipse Link e logs agora ficam em abas dentro de Configurações. Cada download é uma linha densa, com barra azul (vermelha se falhar, verde ao concluir).

## English

New compact IDM-sized window (980×620): white background, black text, and themes are gone. Navigation: Downloads, Torrents, Recordings, Settings, Donate and About. Tools, language, network, extension, Apocalipse Link and logs now live in tabs inside Settings. Every download is a dense single row with a blue progress bar (red on failure, green when completed).

## 简体中文

全新紧凑窗口，大小与 IDM 相同（980×620）：白底黑字，已移除主题。导航：下载、种子、录制、设置、捐赠、关于。工具、语言、网络、扩展、Apocalipse Link 和日志现在位于设置内的标签页。每个下载为一行紧凑显示，进度条为蓝色（失败为红色，完成为绿色）。
