## Durable queue

`queue.sqlite3` becomes authoritative after one migration from `queue.json`.
The original JSON and a `.pre-sqlite` backup are retained. SQLite is bundled
through rusqlite 0.43.0 / libsqlite3-sys 0.40.0 (SQLite 3.54.1), beyond the
upstream WAL-reset fix. Use WAL only on positively identified local storage;
Windows remote drives and unrecognized filesystems use DELETE journaling.
Every save is a transaction with a revision check, updating only changed rows.
Disk errors roll back both database changes and the cache; stale processes
cannot overwrite another process's queue. Restart normalization is transactional.
Malformed databases, foreign application IDs, unknown future schemas and invalid
legacy JSON fail closed while preserving their files for recovery.

The new Export list button writes a complete JSON snapshot through a synced
replacement file. JSON import extracts sources as new downloads; it never replays
foreign destination paths or execution states. Export cannot replace the active
database or its journals. Moving the portable data directory uses SQLite's online
backup so committed WAL transactions are included. Keep the backup for recovery;
older ADM versions do not read the new database and their old JSON can be stale.

## Engine and QUIC Link

The Rust library pin and the packaged backend both resolve to Nibiru source
`42746888a696f0f2f8816893c2dc448f17cd883f` (0.3.0); CI builds the executable from
Cargo.lock's identical revision. The native RPC remains compatible, and browser
extensions stay at 0.3.217. The engine keeps its maximum of 16 HTTP workers and
4 MiB buffers. Its new features and limitations are documented upstream.

QUIC Link keeps pinned TLS, authenticated selected-file access, SHA-256 and
atomic no-overwrite publication. A bounded supervisor retries additional paths
beside the stream and retains per-path RTT, UDP counters and retry data. Tests
reopen an explicitly abandoned secondary loopback path while retaining the
primary. UDP counters include overhead, not application goodput. The
[physical-interface harness](../experiments/transport-lab/benchmarks/README.md)
rotates single-uplink and multipath profiles, verifies hashes and records wall
times. This container has no independent multi-WAN paths, so aggregation and
physical link-failure results remain unverified and experimental.

## Verification and publication

Local checks before the final engine pin passed 253 ADM Rust tests, all 441
JavaScript tests, and eight transport-lab tests including recovery. The final
engine pin is rechecked before publication. Queue regressions cover JSON migration,
backups, committed WAL backup, export protection, failed transaction rollback,
stale concurrent writers, corrupt/future databases and source import. CI validates
Windows x64, Linux x64 and macOS Intel x64 before release assets are published.

The public three-language site received anonymous aggregate analytics on
27 November 2026. It stores only daily locale/event/target counts, supports DNT/GPC,
and cannot reconstruct earlier traffic or count unique people. Its verified public
GitHub cache refresh path is prepared for linked cloud maintenance. Release data
updates do not require republishing the layout; new feature descriptions remain
restricted to versions that contain them. No view or speed guarantees are made.
